# bakery-pruchase-pattern-analysis

Python | Pandas | Data Cleaning | Transaction Analysis | Data Visualization

# Overview

This project analyzes customer purchasing patterns using a bakery transaction dataset. The analysis focuses on cleaning transaction records, identifying frequently purchased products, and examining which products are commonly purchased together.

The goal is to use transaction data to identify purchasing trends that could support product recommendations, promotions, and inventory planning.

# Dataset
The dataset contains bakery transaction records with information including:

- Transaction ID
- Date
- Time
- Purchased Item

The original dataset contained 21,293 transaction records and was used as part of a data science course project.

# Analysis
The project includes:

- Data cleaning and validation
- Identification of frequently purchased products
- Transaction-level analysis
- Product co-occurrence analysis
- Identification of frequently purchased product pairs
- Visualization of purchasing patterns

# Key Findings
- 20,507 valid transaction records remained after cleaning.
- The dataset contained 94 unique bakery products across 9,465 transactions.
- Coffee was the most frequently purchased item, with 5,471 purchases.
- Bread + Coffee was the most frequently purchased product combination, appearing together in 852 transactions.
- Cake + Coffee and Coffee + Tea were also common combinations, appearing together in 518 and 472 transactions, respectively.
